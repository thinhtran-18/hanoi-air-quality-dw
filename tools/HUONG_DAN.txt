CÔNG CỤ NGUỒN VÀ KIỂM TRA ĐỒ ÁN KHÔNG KHÍ HÀ NỘI
Cập nhật 28/11/2026. Chạy từ gốc repository, không dùng đường dẫn .work cũ.
Hướng dẫn toàn tuyến: docs/huong_dan_chay.md.

1. ĐỐI SOÁT NGUỒN HIỆN CÓ
python tools/doi_soat_nguon.py
Đọc 325 file data/raw/*.csv.gz và CSV chốt; kỳ vọng 23.036 dòng, 0 khác biệt,
issues rỗng. Không thêm --write khi chỉ kiểm tra vì tùy chọn này ghi lại hồ sơ.

2. TẢI LẠI TỪ MANIFEST KHI CẦN THỰC HÀNH
python tools/tai_nguon_va_sql.py --out-dir .local/thuc_hanh/raw
Tên script giữ từ trước nhưng hiện chỉ tải .csv.gz, không sinh SQL.
Manifest mặc định: data/source/hanoi_air_quality_vn_source_manifest.txt.
URL = https://openaq-data-archive.s3.amazonaws.com/ + mỗi dòng manifest.
Tệp đích đã có được giữ nguyên. Tải mạng cần kiểm tra riêng sau khi hoàn tất.

3. GHÉP CSV
python tools/kiem_tra_csv.py --output .local/thuc_hanh/ghep.csv
Mặc định đọc data/raw; muốn đọc nguồn vừa tải:
python tools/kiem_tra_csv.py --raw-dir .local/thuc_hanh/raw --output .local/thuc_hanh/ghep_tai_lai.csv
Đọc bằng gzip + csv, ghi tiêu đề một lần, UTF-8 BOM; từ chối ghi đè tệp đích.
Không dùng copy/b hay nối văn bản vì có thể lặp tiêu đề và sai dấu nháy.

4. SINH SCRIPT SQL TỪ CSV
python tools/tao_sql_server.py --csv .local/thuc_hanh/ghep.csv --output .local/thuc_hanh/nguon_moi.sql
Lệnh chỉ sinh tệp SQL, chưa kết nối SQL Server. Script sinh mới dùng database
hanoi_air_vn cố định và từ chối chạy nếu bảng nguồn đã tồn tại. Script nguồn
đã chốt trong sql/source hỗ trợ nạp lại khóa còn thiếu; hai bản khác mục đích.
Muốn thử trên database khác, rà và chỉnh USE/CREATE DATABASE trên bản sao trước
khi Execute. sqlcmd -d không ghi đè USE bên trong file.
CSV ghép mới có thể khác thứ tự dòng nên IDENTITY sinh lại có thể khác SourceId
đã dùng trong kho. Không thay bảng nguồn dưới kho đang tồn tại bằng bản thực hành.
Thực hành sinh nguồn mới cần cô lập cả nguồn lẫn kho; dự án dùng SQL chốt để giữ lineage.

5. NẠP BẢN NGUỒN ĐÃ CHỐT
SSMS / File / Open / File / sql/source/hanoi_air_quality_vn_monitoring_real.sql
Kiểm tra đúng server và database trong mã / Execute / xem 23.036 dòng nguồn.
Không import thêm CSV nếu đã chạy SQL chứa dữ liệu. Kho PM lấy 11.500 dòng.
Ánh xạ CSV: location_id -> location_id; sensors_id -> sensor_id;
location -> location_name; datetime -> observed_at DATETIMEOFFSET giữ offset;
lat/lon -> latitude/longitude DECIMAL(10,6); parameter -> parameter;
units -> unit; value -> value FLOAT(53). id là IDENTITY SQL, không có trong CSV.
Không dùng số thứ tự CSV làm SourceId.
